## 如何使用归档

[ADR 0002](../decisions/0002-rust-source-transition.zh.md)将 C++ 实现方向改为 Rust。[ACTIVE](../../ACTIVE.md)、[PRD](../product-requirements.zh.md)及[当前架构提纲](../architecture/caption-meet-architecture.zh.md)负责当前范围与未决工作。

归档中的状态、命令和授权保留原始语境，不批准新的执行、不关闭 gate，也不验证 Rust。引用时保留原有失败和验收边界。
