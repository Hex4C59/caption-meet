## 背景

维护者选择用 Rust 编写全部自行维护的应用代码，包括浏览器界面、后端和 SFU，随后明确要求先删除全部 C++。这取代了 [ADR 0001](0001-vendor-rtcpilot-in-tree.zh.md) 中的 C++ 实现方向与仓内源码维护要求；保留署名的要求继续有效。

## 决策

1. 从工作区删除 RTCPilot 的 C/C++ 实现、头文件、原生测试、随附原生依赖、原生构建工程和原生产物。
2. 保留 RTCPilot LICENSE、导入来源、依赖许可证与版权声明，以及历史报告。保留的上游文档描述已删除的实现。
3. 后续自行维护的应用代码、测试和工具使用 Rust。本次清理不迁移现有 Python/JavaScript 工具，也不引入 Rust 实现。
4. 保留三人局域网音视频会议及逐人中文字幕目标。媒体仍须经 SFU；识别服务保持外置，替代接入须验证契约与隔离。
5. Rust 框架、WebRTC 库、协议、进程及模块方案尚未确定。此前建议只是候选，不是已接受的选型。

## 影响与验收边界

工作区不再包含可构建的 SFU 或原生回归测试。历史 C++ 构建与媒体结果不能证明后续 Rust 代码。WI-004 被替代，物理设备验收仍未完成；原报告保留，仅在源码删除导致链接失效时调整链接。

本决策只接受源码布局转向。删除代码不关闭信令、媒体、生命周期、准入、字幕、容量或 Rust 构建 gate。后续实现须单独确定范围并验证。
